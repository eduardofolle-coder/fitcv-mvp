# FITCV Design System

## 🎨 Color Palette

### Primary
- `blue-600`: #2563eb (Primary action)
- `blue-700`: #1d4ed8 (Hover state)
- `blue-50`: #eff6ff (Light background)

### Secondary
- `indigo-600`: #4f46e5 (Accent)
- `indigo-50`: #eef2ff (Light accent)

### Status
- `green-600`: #16a34a (Success)
- `red-600`: #dc2626 (Error/Danger)
- `yellow-600`: #ca8a04 (Warning)
- `gray-600`: #4b5563 (Info)

### Neutral
- `gray-50`: #f9fafb (Background)
- `gray-100`: #f3f4f6 (Secondary bg)
- `gray-900`: #111827 (Text dark)
- `gray-600`: #4b5563 (Text secondary)

## 🔤 Typography

### Heading
- H1: 36px, 900 weight (Hero titles)
- H2: 30px, 700 weight (Section titles)
- H3: 24px, 700 weight (Card titles)
- H4: 18px, 600 weight (Subsections)

### Body
- Large: 18px, 400 weight
- Regular: 16px, 400 weight
- Small: 14px, 400 weight
- Extra Small: 12px, 400 weight

### Accent
- Semibold: 600 weight (highlights)
- Bold: 700 weight (emphasis)

## 🎯 Components

### Button Sizes
- **sm**: 12px padding, 14px text
- **md**: 16px padding, 16px text (default)
- **lg**: 24px padding, 18px text

### Button Variants
- **primary**: Blue with white text
- **secondary**: Gray with dark text
- **danger**: Red with white text
- **ghost**: No background, text only

### Card Spacing
- Padding: 24px (6rem)
- Border radius: 8px
- Shadow: md (default)

### Input Fields
- Height: 40px
- Padding: 16px
- Border: 1px gray-300
- Focus: Blue ring + border
- Error: Red border + ring

## 🌈 Responsive Breakpoints

- Mobile: < 640px (sm)
- Tablet: 640px - 1024px (md, lg)
- Desktop: > 1024px (xl, 2xl)

## ✨ Spacing Scale

- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- 2xl: 48px

## 🎬 Animations

- Transition: 200ms ease-in-out
- Hover scale: 1.05x
- Loading spinner: 1s linear infinite

## 📱 Mobile First

All components designed mobile-first, then enhanced for larger screens.
